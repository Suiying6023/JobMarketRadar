# 中国 IT 外包 / 人力派遣 / 人力服务公司名单
# 用途：岗位筛选时识别"外包/外派/人力服务商"岗位
# 格式：每行一个公司名主体（不带"有限公司""股份有限公司"等后缀也可以，
#       匹配器按"公司名以该词开头"或"包含该词且长度>=4"判断）
# 分类注释用 # 开头
#
# ── 匹配规则（与上面的格式说明配套，务必一起读）─────────────────────────
# 本文件不写逐行标记，层级由「词长」唯一决定，匹配器按两条规则处理：
#
#   规则 1（强词：len>=4 汉字，或 len>=6 拉丁字符）—— A~F 段
#       允许「子串包含」：company_name 里出现该词即命中。
#       例：`上海万宝盛华信息科技` 含 `万宝盛华` ✓
#           `北京外企德科人力...`（库内截断名）含 `外企德科` ✓
#
#   规则 2（短词：len<4 汉字 且 len<6 拉丁字符）—— G 段
#       **禁止子串包含**，只允许两种命中：
#         a) company_name == 词
#         b) 去掉 2~4 字省市前缀后，company_name 以该词开头
#       例：`深圳中智` → 去 `深圳` → 以 `中智` 开头 ✓
#           `浙江中智经济技术合作` → 去 `浙江` → 以 `中智` 开头 ✓
#           `华中智能科技` → 不以 `中智` 开头，去前缀后是 `智能科技` ✗
#           `华秋智联`（会被裸 `智联` 命中）→ `华秋` 不是省市前缀 ✗
#           `厦门鹭港智联算力` → 去 `厦门` 后是 `鹭港智联算力` ✗
#           `海宇信息`（会被裸 `宇信` 命中）→ `海宇` 不是省市前缀 ✗
#           `山东软件科技`（会被裸 `东软` 命中）→ 去 `山东` 后是 `软件科技` ✗
#           `上海微创医疗器械`（会被裸 `微创` 命中）→ 去 `上海` 后是 `微创医疗器械`，
#                仍以 `微创` 开头 —— 所以 `微创` **不入名单**，只收 `微创软件`
#
# 为什么必须这样分：2~3 字的中文主体名做子串匹配一定误报，实测已踩过
# 智联 / 宇信 / 东软（山东软件）/ 微创（微创医疗）/ 海隆（海隆石油）/ 宝信（宝信汽车）
# 六个坑。详见 local/research/20261019/STAFFING-COMPANIES.md
#
# 本文件只收「确定」或「高置信」主体；疑似名单（恒生电子、金证股份、太极股份、
# 东华软件、华胜天成、浪潮、宝信软件、中电太极、信雅达、亚信科技等）见研究报告，
# 人工复核后再决定是否并入本文件。
# ─────────────────────────────────────────────────────────────────────
