    数据说明

    读这份数据前需要知道的几条边界。它们不是免责声明，是会直接影响判断的口径。

    这是本地偏样本，不是全网

    岗位只来自本机既有的采集结果，受关键词、城市、翻页深度、账号可见范围与采集时间窗共同限制。 它既不是 BOSS 全量，也不是随机抽样：越是被配置里反复采的关键词，在库里的相对占比就越高。 因此「技能 Top N」「行业分布」只能读作本库内的相对频率，不能外推成市场占比。

    薪资是挂牌薪资

    薪资字段是招聘方在平台上标注的区间（例如「15-25K·14薪」），通常面向所有候选人， 不是给你的 offer，也不是到手收入。统计里的中位数取区间中点 （下限与上限的平均），不折算年终奖倍数，并排除日薪 / 时薪与明显异常值 （下限 ≤ 0、下限大于上限、或超过 300K）。

    活跃度与在招状态是带时间戳的快照

    「在线」「刚刚活跃」「招聘中」都是抓取详情那一刻的状态，此后不随时间自动衰减。 一个月前记录的「刚刚活跃」今天既不能证明在线，也不能证明不在线 —— 它的信息量接近于零。 因此列表里给出「详情快照」时间与快照年龄：超过 7 天即标记为偏旧、 需要重新核实；没有时间戳的（未抓详情、或正文缺时间）单独算作状态未知，不按新鲜岗位推荐。

    快照状态只区分「已标关闭」与「未标关闭，当前待核实」两种情况。 概览里的「未标关闭」统计的是快照没有标关闭的全部记录（含没有 JD 的）， 它是"没有看到关闭标记"，不是"确认在招"。

    「优先核实」不是确认在招

    岗位池的优先级（优先核实 / 需核实门槛 / 暂不优先 / 信息不足）是本地规则给出的 核实排序建议：它综合了画像匹配、门槛与快照新鲜度，用来决定「先去核实哪一条」。 任何一条在被人工或平台确认之前，都不代表岗位仍在招聘，也不代表你可以投递。

    收藏 / 已投 / 备注只是本地记录

    这三个标记写在本机数据库里，用来记录你自己的进度。它们不会向 BOSS 发送任何内容， 也不代表简历已投出、更不代表对方已收到。重置只会清掉本机的这三个字段。

    重复与状态未知

    「疑似重复」的判据是公司标识（或规范化公司名）+ 规范化标题 + 城市相同， 它只提示合并候选、不删原记录，也不等于跨平台已去重。状态未知表示没有 JD 正文、 或正文缺时间戳；这类岗位在统计里有独立的位置，不会被算作「在招」。

    离线冻结：本页不会解除

    顶栏显示的是当前安全状态与原因。本页只读本地数据、只写本地配置与本地标记， 没有任何采集、开聊或解除冻结的入口；冻结到期或需要人工解除时，按项目既有的命令行流程处理。

    导出

    「导出 CSV」导出的当前筛选结果（未分页），由本地服务直接生成，不联网。 导出内容同样受上面的口径限制。
