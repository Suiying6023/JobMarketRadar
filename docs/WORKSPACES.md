# 服务与使用工作区

JobMarketRadar 提供通用岗位采集、详情补全、状态刷新、LLM 标签、存储、任务、配置与岗位池总览。学历、毕业届别、工作年限、求职意向、技能目标、可达性评分和推荐可作为通用配置与结果保存。

面向个人的行业研究、简历、投递、面试与项目训练使用独立工作区。分析读取一致性快照或导出，结果通过岗位主键和来源时间关联。

```text
Boss/
  src/ tests/             工程代码与测试
  data/                   岗位数据、运行状态与日志
  local/                  本地技术档案、一次性研究与交接
JobHunt/
  data/                   分析快照与来源
  analysis/ reports/      研究代码与报告
  resume/ jobs/           简历与岗位复核材料
  interview/              面试与学习材料
```

新服务的网页、HTTP API 和 Agent CLI 管理同一套任务。配置明确生效时点，连接与浏览器在新任务中建立。通用默认画像保持宽泛，使用者按目标调整。

真实数据、浏览器会话与个人配置属于本地资料；公开工程使用合成示例。历史脚本与技术档案按来源和日期保留，判断以当前代码和实际证据为准。
