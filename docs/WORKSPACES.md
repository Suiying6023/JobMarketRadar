# 服务与使用工作区

JobMarketRadar 提供通用岗位数据能力：采集、详情补全、状态刷新、LLM 标签、存储、配置以及岗位池总览。学历、毕业届别、工作年限、求职意向、技能目标、可达性评分和推荐可以作为通用配置与结果保存，具体取值由使用者提供。

面向某个人的行业研究、简历、投递、面试与项目训练保存在单独的使用工作区。分析读取一致性快照或导出，结果通过岗位主键与来源时间关联。数据采集、通用评分以及个人决策分别记录依据与版本。

建议目录：

```text
Boss/                  工程、通用文档与运行配置
  src/ scripts/ tests/ 通用代码与验证
  data/ logs/          本地数据库、原始数据与日志
  local/               本地技术档案、备份与交接
JobHunt/               个人使用工作区
  data/                分析快照与来源清单
  analysis/ reports/   分析代码与研究结果
  resume/ jobs/        简历和岗位复核材料
  interview/           面试、项目与学习材料
```

现有版本提供采集脚本与离线管理页。一站式服务启停、统一任务日志、LLM 配置、人验状态联动，以及本地默认和可选代理路线是后续服务重构内容。

历史经验参数作为可调参考；`budget_mode=reference` 默认提示，显式 `enforce` 才执行本地限制。在线访问按当前配置、持久状态和实际平台响应判断。

`local/`、真实岗位数据、浏览器会话与个人工作区属于本地资料。公开工程使用合成样例和可复用配置。
