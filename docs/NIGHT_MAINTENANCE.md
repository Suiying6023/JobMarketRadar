## 暂停与到期

- 验证码、登录复检、限流、账号/IP/环境访问限制触发waiting_verification和持久暂停。
  维护发现后停止本计划平台任务、记halted，后续只离线整理和报告，不自动release/resume。
- 任务失败或中断也停止自动取数。明确的软件故障修复、访问ready且无活动任务后，
  `--review-task ID --review-reason "证据与修复"`可以记录复核；有risk/verification事件时拒绝软件放行。
- 到08:00停止本计划仍运行任务。如果配置修订号仍是维护最后保存的值则恢复原配置，
  外部修改过则保留外部修改。访问暂停状态始终保留。
- 服务不可读时记录halted与未确认停止状态，不自动重启。先现场确认服务和任务，再有依据地复核；
  定时会话不能把连接恢复当作平台恢复。模型故障不会丢失已创建的平台任务归属。

独立刷新通道仍是休眠收尾暂停，不自动重建出口或解除它。正常网页/合法App入口分别核验；
验证码或访问限制不会通过换身份、换出口、解验证码继续。
