# 从网页业务与数据证据构建采集器

2026-10-01。这一轮保留 SQLite、批次与任务服务，拆开浏览器控制和岗位字段解析。四条业务链路仍为列表、详情、LLM 抽取、独立状态刷新。原项目同源详情已新增75份正文；原生列表和卡片详情完成三城市小样本验收，详见 [原生通道](NATIVE_COLLECTION.md)。

## 已有证据与仍待验证的部分

| 问题 | 当前证据 | 实现含义 |
|---|---|---|
| 搜索如何产生结果 | 本机官网页面发出列表 POST；本轮既有采集器已完成18组查询，保存1024个岗位 | 页面请求方法和参数须按实际业务请求确认，不把已有GET适配器当成官网唯一接口方式 |
| 详情如何产生 | 页面会自动展示一个岗位，并发出详情GET；公开源码也通过点击卡片等待原生详情响应 | 等待对应业务结果，不用HTTP200或页面打开成功代替正文获取成功 |
| 岗位身份 | 列表encryptJobId与详情jobInfo.encryptId可对应同一岗位 | 主键使用platform:source_job_id；标题、公司文字和详情凭据均不作为主键 |
| 临时上下文 | 列表/详情记录包含securityId、lid；本地曾发生跨浏览器登录导致主会话失效 | 凭据带来源时间和会话语境；失效后重新观察该岗位，不将长期保存的凭据当永久岗位地址 |
| 正文与登录 | 失效会话曾返回半段或400字预览；主轮现有217条非空正文，完整访问核验93条，93份当前输入标注 | 非空正文、解析成功、认证完整访问分别记录；继承旧正文不能伪装成新轮全文；anonymous与匿名公司相关，不能当登录判据 |
| 在线与在招 | 列表bossOnline与详情activeTimeDesc是不同字段；刷新可有独立状态结果 | 招聘者在线、活跃文字、岗位状态和正文时间不能互相替代 |
| 浏览器空白 | 普通浏览器正常；标准MCP窗口自动跳转/关闭，日志显示页面脚本尝试关闭窗口 | 浏览器异常单独停止任务；不从空白推断封号，不循环导航，也不把本机控制台验收外推到官网 |
| 页面复制与数字 | 用户新开的普通Chrome可显示推荐列表与职位描述；画面薪资为普通数字，复制文本中的薪资为私用区字体字符 | 页面复制不作为批量结构化数据源；不要将字体字符误解析为金额，保留可见字段证据 |
| 会话来源 | 用户已在原项目login窗口完成登录；.browser-profile同源详情及原生通道均实际可用 | 普通Chrome、MCP、原项目Profile和跳板匿名Profile分别核验，不跨会话推断 |

以上字段含义来自本机真实响应和公开实现的交叉核对，不是BOSS官方接口契约。现行列表表单与详情请求已观测，任意筛选组合、搜索全量覆盖、长期稳定性仍不外推。此前研究见私有工作目录的 `architecture-review.md`、`browser-compatibility.md`，本次补充见`extra-project-review.md`与 [原生通道](NATIVE_COLLECTION.md)。

## 简化后的结构

```mermaid
flowchart LR
    W[正常网页业务或允许导出的数据] --> C[采集通道]
    C --> P[岗位字段解析]
    P --> S[SQLite岗位与来源证据]
    S --> R[本轮观察与查询断点]
    S --> L[独立并发LLM抽取]
    J[独立状态刷新] --> S
    R --> X[带批次来源的只读快照]
    L --> X
    X --> A[JobHunt新旧对照]
```

| 层 | 实际入口 | 责任 |
|---|---|---|
| 浏览器与传输 | collectors/browser.py、collectors/boss.py | 导航、请求、页面健康、登录/验证处理、请求记账；不承担字段转换 |
| 字段解析 | collectors/boss_payload.py | 列表与详情转JobRecord；核对非空岗位ID、详情ID和正文；不联网，也不凭JSON自行证明登录 |
| 存储 | storage.py、rounds.py | 去重、观察时间、正文时间、批次、旧正文保护、只读快照 |
| 模型 | llm.py、annotations.py | 从原文抽事实，保留输入/模型/提示词版本；标签用于导航和复核 |
| 执行与界面 | service_jobs.py、tasks.py、worker.py | 四条链路的计划、暂停、进度、日志；网页和CLI共用 |

不增加消息队列、独立微服务或额外数据库。网页访问先串行，LLM并发独立调节；SQLite写入留在工作进程主线程。跳板的匿名岗位业务未验收，保留为可选状态通道，不能用其登录行为影响本机详情会话。

普通桌面截图和页面复制只用于少量业务实证，未构建大批量GUI采集链路。当前读取的是推荐视图，不能记成关键词搜索样本，也未将其插入本轮岗位库。

## 数据更新规则

- 列表回答“本次查询看到了哪些岗位”；排序靠前或未被搜到，都不能证明市场完整覆盖或岗位已关闭。
- 详情核对岗位ID后再写正文及同次详情的薪资、学历、经验等元数据；解析使用副本，失败不留下半更新对象。
- 详情来源记录观察时间、岗位ID、正文SHA-256和外部提供的访问核验状态。解析器默认不认定完整访问。
- 近期但访问未知的正文仍进入详情队列；LLM每批执行前重新检查正文条件，已标为访问未核验的正文不进入抽取。
- 批次快照保存岗位、查询计划、查询完成记录、观察记录及模型/状态证据；分析明确区别本轮新取的核验正文和继承正文。
- 模型输入截断与模型输入过期分别记录。原文变动后旧标注仍保留，但不能用作当前正文的结论。
- 平台停止事件保留code、HTTP状态和文案分类：账号/网络/环境限制、认证需要复检、频率限制或未确定验证原因。分类只帮助复检，不自动放行或重算校验凭据；只读错误信封文字，不扫描成功JD中的技术词。
